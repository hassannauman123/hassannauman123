# Install this GitHub profile README

1. On GitHub, create a **public** repository named exactly `hassannauman123`.
2. Upload `README.md` to the repository root.
3. Upload `assets/banner.svg` preserving the `assets` folder.
4. Visit https://github.com/hassannauman123 and refresh.
5. Edit the README to add your actual LinkedIn URL and your new monitoring repository link after publishing it.
6. In GitHub profile settings, update your short bio and pin your three strongest infrastructure/cloud projects.

Notes: The sidebar avatar, follower count, achievements, and pinned repositories are controlled by GitHub, not the README. Third-party stats cards may occasionally be unavailable. Project descriptions should be checked against what is actually implemented. Do not publish credentials, real healthcare data, or sensitive screenshots.
